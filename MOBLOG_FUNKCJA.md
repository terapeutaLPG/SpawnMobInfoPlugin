---

## 🎮 Jak używać MobLog:

### 1. **Otrzymaj narzędzie**

```
/blazekill logitem
```

Otrzymasz diamentową łopatę "MobLog" z enchantem Luck 1

### 2. **Sprawdź moba**

- Kliknij **prawym przyciskiem** na moba łopatą MobLog
- Zobaczysz informacje o zespawnowaniu

### 3. **Przykład wyniku**

```
=== MobLog Info ===
Typ moba: BLAZE
Zespawnowany przez: Player123
Czas spawnu: 07-07-2025 15:30:25
Lokalizacja spawnu: 123, 64, 456
```

---

## 🔍 Co sprawdza MobLog:

- **Wszystkie moby** zespawnowane przez spawn eggs
- **Nie tylko Blaze i Ghast** - każdy mob z jajka!
- **Informacje o spawnerze** - kto go zespawnował
- **Czas spawnu** - dokładna data i godzina
- **Lokalizacja spawnu** - współrzędne

### Jeśli brak danych:

```
Brak informacji o spawnie tego moba
Mob mógł zostać zespawnowany naturalnie lub przed uruchomieniem pluginu
```
